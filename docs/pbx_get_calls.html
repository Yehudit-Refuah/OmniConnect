1. The request

Endpoint
GEThttps://<host>/api/pbx/v1/calls (host to be provided)
Header
X-API-Key: <key> on every request (key sent to you securely).

3. Fields

FieldExampleMeaning
attempt_ida-test-0001ID of this call attempt. Send it back in every POST about this call.
phone+18455550100Number to dial (E.164).
patient_nameTest PatientPatient's full name.
mrnTEST000001Medical record number.
visit_datetime2026-11-23T09:30:00-05:00Visit date and time.
facility / facility_addressTest FacilityVisit location.
providerDr. ExampleProvider name.
languageen-USen-US or es-US, for the text-to-speech voice.
operator_extension1100Transfer here if our API can't be reached.
do_not_call_after2026-11-22T20:00:00-05:00Don't start dialing after this time.

The answer may include a few more fields used for logging. Please ignore any field you don't recognize.
